# DocuFlow — demo v2

Prototipo Streamlit para explorar el seguimiento de documentación de clientes de una asesoría.

## Ejecutar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Importante

- Los datos de ejemplo son ficticios.
- Los cambios viven únicamente en la sesión y pueden desaparecer al reiniciar.
- No se envían emails ni se guardan documentos.
- No usar con datos personales, fiscales ni confidenciales.
- No es una aplicación de producción: no incluye autenticación, base de datos ni controles de seguridad para datos reales.
